# 架构与审查参考索引

先识别实际 UI、运行载体、业务服务及状态归属，再选择参考；后端语言不决定 UI 类型。以下组合用于定位示例，具体组件、传输与服务部署根据命令/事件契约、状态一致性和运行条件选择。

| 项目形态 | 技术栈示例 | 读取内容 | 审查入口 |
|---|---|---|---|
| 浏览器中的 Web 页面 | HTML/CSS/JS，或 React/Vue + 既有接口 | [Web](web.md) | 实际页面与相关服务 |
| Web Renderer + Node 业务服务 | Electron + React/TypeScript + Node，UI 可组合 Radix、Zustand、表格/图表库 | [桌面共用约束](web-desktop.md)、[Electron + Node](electron-node.md) | 浏览器真实 Bridge + Electron |
| Web Renderer + 外部 Worker | Electron + React/TypeScript + Node 调度 + C# Worker | [桌面共用约束](web-desktop.md)、[Electron + Worker](electron-worker.md) | 浏览器真实 Bridge + Electron/Worker/输出物 |
| Web Renderer + Rust 业务服务 | Tauri + React/TypeScript + Rust，异步与 HTTP 适配可使用 Tokio/Axum | [桌面共用约束](web-desktop.md)、[Tauri + Rust](tauri-rust.md) | 浏览器真实 Bridge + Tauri |
| 原生或其他混合 GUI | C# + WPF/WinForms、Python + PySide/Qt 等示意 | [原生与混合界面](native-hybrid.md) | 真实应用与其实际 UI 载体 |

多个载体同时存在时，只读取本次涉及的部分。自定义 WebView 宿主先确认原生边界，不能仅凭 HTML 强套 Electron/Tauri 的 Bridge 方案。

## 产品标识与图标

- 优先复用既有品牌或原型中的产品标识与图标；未提供时结合产品功能与界面风格设计或选用，保证小尺寸下清晰、可辨识。制作方式、资源格式和尺寸按项目与平台选择。
- Web 应用核对 favicon 与界面应用标识；桌面应用核对窗口、任务栏/启动入口及交付程序、安装包中的对应图标。实际检查加载和显示效果，不能只核对源文件或配置存在。
- 功能图标与操作语义一致、样式协调；图标按钮提供可理解的名称。帮助、箭头等控件图标不能代替产品应用图标。

## 共同审查方法

执行时机、细化清单、覆盖范围与用户复核分工见 [验证与验收范围](verification.md)。以下方法用于已确定需要执行的界面审查。

- Web 界面的交互与视觉审查使用内置浏览器，打开实际运行的页面或 Browser Review Mode；本次审查中的自动交互也通过其操作或自动化能力执行。具体启动命令、URL、支持尺寸和运行依赖从目标项目读取。
- 项目已有 Playwright/E2E 回归及单元、协议与服务集成测试沿用现有工具链。脚本断言、DOM 快照和日志只提供对应证据，不替代内置浏览器中的实际交互与视觉判断。
- 按本次界面清单实际点击、输入、选择、操作菜单或弹窗、滚动，观察操作前后的视觉与反馈，覆盖相关空态、加载、错误、禁用、成功、取消和恢复。
- 响应式与布局审查覆盖项目规定的最小尺寸、典型尺寸及受影响布局断点两侧，同时考虑宽度与高度；观察主要操作可达性、内容溢出、弹层遮挡和滚动。项目没有既定范围时说明此次尺寸依据，不把示例尺寸写成产品承诺。
- 实际查看渲染画面，检查视觉层级、间距、对齐、文字可读性和一致性，按需求与设计规范判断。保存截图后必须查看画面并给出判断，不能仅以截图文件生成成功作为视觉通过依据；DOM、几何断言和日志可辅助定位。
- 测试按钮时从真实 UI 触发；服务调用或状态注入可准备条件、观察结果，不能代替被测操作。涉及后端的验收还要核对事件、服务状态或产物，避免仅根据前端提示判断成功。
- 流程验证从真实 UI 发起，核对链路结果与恢复行为。上位机可按需求检查启动、连接、请求/订阅、确认数据、界面反馈、停止/断开与资源释放；有输出物的应用还须检查实际结果。
- 发现交互或视觉问题后直接修正，复验原问题及受影响流程，直到选定范围符合验收标准；无法解除的阻塞按主流程交代未完成项。
- 内置浏览器、原生交互工具或环境缺失时检查适用替代，替代方式仍须能操作真实应用并查看实际画面；继续独立检查，无法实际操作或观察的部分列为未验证。对同一阻塞无新证据时停止盲目重试，说明恢复条件。
