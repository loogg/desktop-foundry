# 组织与标注示例

以下例子只帮助理解正文。按项目需求取用，示例中的 Page、行为和数值不是默认要求。

## Page 组织例子

| 项目情况 | 一种组织方式 |
|---|---|
| 工业测试上位机，既有协议字段又有计算原理 | 产品界面、设计系统、数据模型、理论与计算依据分别放 Page；界面标注指向相关字段或公式。 |
| 小工具，只有少量字段和一条公式 | 保留界面与所需共用资源；字段和公式就近标注，或合并为简短说明区。 |
| 已有完整设计文件，仅改一个功能 | 在原功能 Section 中修改相关视图与状态，沿用已有 Page 与资源库。 |

## 复杂组件示意与标注

| 对象 | 画面表达 | 关联 Annotation 的文案例子 |
|---|---|---|
| 趋势曲线 | 用图表组件展示坐标、曲线、图例及所需选中效果。 | 此处用于表达曲线布局、数据含义及联动意图；正式开发使用专用图表组件实现，图中数据仅为示意。 |
| 仪表盘 | 展示量程、当前值与项目需要的阈值区间。 | 此仪表表达读数与阈值区间的视觉关系；正式开发使用专用仪表实现，量程和阈值取项目配置。 |

## 不同 Page 中的 Annotation 例子

| 所在位置与关联对象 | 文案例子 |
|---|---|
| 产品界面：暂停显示按钮或日志区 | 暂停只冻结列表显示，仍继续接收；恢复后补入暂停期间的数据。 |
| 设计系统：窗口布局示意 | 窗口变窄后侧栏折叠，主内容区伸缩，日志区内部滚动；此图说明布局规则，不按整页缩放实现。 |
| 数据模型：某个字段定义 | 此字段含义已确认，取值范围待确认；相关界面见“设备配置”视图。 |
| 理论依据：公式与示例计算 | 此算例使用固定输入说明计算过程；适用条件与单位见本节，不代表设备实测结果。 |
